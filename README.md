Chapter 2: Processing Data (C#)
1. Variable: A variable is a storage location in memory.
2. Data Types: int (whole numbers), double (decimal numbers), string (text), decimal (money).
3. TextBox: Used to enter data.
4. Concatenation: Joining strings using the + operator.
5. Calculations: C# uses +, -, *, /, %.
6. Parse: Converts string input into numeric values.
7. ToString(): Converts a value into a string.
8. Exception Handling: Uses try-catch to handle errors.
9. Constant: A value that cannot be changed. Uses const.
